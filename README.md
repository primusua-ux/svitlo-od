# Світло є? Одеса

Мобільна сторінка з картою Одеси: торкніться будинку і побачите, чи є світло зараз за графіком погодинних відключень ДТЕК Одеські електромережі.

Сторінка: https://primusua-ux.github.io/svitlo-od/

Сторінка неофіційна. Черги за адресами зібрано з [офіційної сторінки ДТЕК](https://www.dtek-oem.com.ua/ua/shutdowns), графік береться з відкритих дзеркал цієї сторінки ([outage-data-ua](https://github.com/Baskerville42/outage-data-ua), [outages-data](https://github.com/mrkaktuz/outages-data)). Карта і координати будинків: © учасники OpenStreetMap (ODbL).
